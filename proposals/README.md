# Proposals

Per-pattern proposal files generated by
[`tools/reverse_autopilot.py`](../tools/reverse_autopilot.py).

## What lives here

- `repeat-*.md` — one file per detected recurring user-side pattern.
  **Gitignored** — derived from local transcript history; may surface
  project paths or private context. Review individually before
  committing or sharing.
- `README.md` — this file (the only tracked content in this directory).

## How to refresh

```
py -3.14 tools/reverse_autopilot.py \
    --output-dir proposals/ \
    --min-occurrences 5 \
    --min-sessions 3
```

`tools/reverse_autopilot.py` scans `~/.claude/projects/*/<session>.jsonl`,
extracts the first N words of every non-system user message, and writes
one proposal per pattern that recurs across enough sessions.

## What's in a proposal

- Frequency + distinct-session count
- Time window of first/last sighting
- Suggested form: `script`, `prompt-template`, or `noise`
- Up to three example messages
- Adoption hint (where the script / template would land)

The tool **never** writes files outside this directory. You decide
whether each proposal turns into a tool/template/prompt or gets
discarded.
