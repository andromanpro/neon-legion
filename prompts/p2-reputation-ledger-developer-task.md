```json
  ],

```

When `total_runs_scanned == 0`, `ledger` is `[]` and `sparse: true`.

## roles.suggested.toml schema

A subset of `roles.used.toml`'s structure with score-driven comments:

```toml
# Generated by tools/reputation_ledger.py at <timestamp>.
# Never auto-applied — human reviews and copies edits into roles.toml.
# Sample size: <total_runs_scanned> runs. Marked `sparse=true` if N < min_runs.

[role.architect]
# Score: success_rate=100% over 1 run, mean_duration=2ms
# Suggestion: keep current (claude). Confidence: low (single-run sample).
model = "claude-opus-4"
invocation = "claude-code"

[role.developer]
# ...
```

If no data → `roles.suggested.toml` is a minimal file with just a comment header explaining "no historical runs found, suggestions unavailable yet". Don't crash.

## Scoring logic (MVP — keep simple)

For each (role, agent) tuple aggregated across all qualifying runs:

- `runs` = count of steps for this (role, agent) where status="completed".
- `successes` = count where `result.ok == true`.
- `success_rate` = successes / runs (0.0 if runs == 0).
- `mean_duration_ms` = mean of `result.duration_ms` across completed steps.
- `mean_cost_usd` = null for MVP. Future: correlate with `codex-events.jsonl` by session_id / timestamp. Out of MVP.
- `task_fingerprint` = the role's input prompt's first non-empty markdown header, or "unknown" if not derivable.
- `last_run_at` = max `started_at` across runs.

For `roles.suggested.toml`:

- For each role: if best-scoring agent != currently-assigned agent in `roles.used.toml`, comment `# Suggestion: switch to <agent>` with score rationale. If best == current, comment `# Suggestion: keep current`.
- Add per-role `# Sample size:` line.
