# Capability cards

This directory holds per-agent capability cards generated by
[`tools/capability_cards.py`](../../tools/capability_cards.py).

## What lives here

- `<agent>.md` — one card per agent (e.g. `claude.md`, `codex.md`,
  `deepseek.md`, `human.md`), refreshed locally from
  `tracker/reputation.json`. **Gitignored** — runtime artifact, not tracked.
- `README.md` — this file (the only tracked content in this directory).

## How to refresh

```
py -3.14 tools/reputation_ledger.py   # rebuilds tracker/reputation.json
py -3.14 tools/capability_cards.py    # rewrites docs/capability/*.md
```

## What's in a card

For each (agent, role) the cards surface:

- Run count, success rate, median cost, median latency
- Last-run timestamp
- Top-3 failure modes (from the ledger's `non_success_counts`)
- Aggregate-over-all-roles summary

The cards are descriptive, not prescriptive. For an actual routing
recommendation, see
[`orchestrate-runs/roles.suggested.toml`](../../orchestrate-runs/roles.suggested.toml)
(also generated by `tools/reputation_ledger.py`).

`roles.toml` is **never** modified automatically — a human merges any
changes by hand after reviewing the suggested toml.
